# Match datasets to tasks before expanding

Checked **2026-10-11** for [#24](https://github.com/vibemonkies/hachi/issues/24), reconciled with [PR70](https://github.com/vibemonkies/hachi/pull/70), main `d8f5af9`. None of the nine reviewed sources establishes a newly permitted, held, training-sized wearable illness/recovery cohort. Several support useful separate tasks; enrollment counts do not establish wearable–label–follow-up intersections. Homekit2020/Evidation are promising **future research routes**, but Justin rejected them and CovIdentify for this project’s timeline; no data was obtained. The [registry](../../configs/datasets/) remains authoritative. SnowyFortress/OliveTower agreed that **all proposed experimental branches remain unadmitted**. This builds on the [research catalog](../../docs/RESEARCH.md); researchers checked primary documentation, and CoralFrog independently verified existing local Stanford metadata below. No new download, account, agreement, experiment, or issue was created. Supplementary evidence records retrieval limits, revisions and terms: [public/waveform](<notes/Dataset modality feasibility/public-waveform.md>), [restricted cohorts](<notes/Dataset modality feasibility/restricted-cohorts.md>), [illness/models](<notes/Dataset modality feasibility/illness-models.md>). Their original checkpoints precede PR70’s access decisions.

## Paired clinical follow-up remains the limiting resource

- **Homekit2020:** 5,034 sharing-consented Fitbit users, 206 PCR-confirmed influenza, mean 114 days, 9.8% missing sensors and 85% questionnaire completion. Minute HR/steps/sleep and daily surveys support lab-grounded onset. [Paper](https://proceedings.mlr.press/v209/merrill23b/merrill23b.pdf). The [recovery questionnaire](https://www.synapse.org/#!Synapse:syn22803188/wiki/608061) is administered to an optional subgroup around 14 days after sample return; complete follow-up for 206 is unverified. [Access](https://repo-prod.prod.sagebase.org/repo/v1/entity/syn22803188/wiki/609492) requires individual Synapse certification/validation, public intended-use/institution/IRB information, acceptance, restricted redistribution and a royalty-free Evidation license to resulting IP. **Unavailable for this project**: certification/validation never completed, access never requested. [Registry decision](../../configs/datasets/homekit2020.toml).
- **Evidation ILI:** 71,556 survey participants, but dense wearable subsets are **41 COVID / 85 concurrent-flu / 1,226 pre-COVID-flu participants**. [Paper](https://homes.cs.washington.edu/~althoff/docs/characterizing_covid_and_influenza_cell_patterns_2021.pdf). Released [activity](https://www.synapse.org/#!Synapse:syn22891469/wiki/607239) is daily steps/RHR/sleep, with observed/imputed/normalized/model-output columns; use observed channels. Onset/recovery and day-relative surveys support censoring-aware recovery. Individual validation, approved research plan/signed conditions, deletion and requested progress reporting are [access barriers](https://repo-prod.prod.sagebase.org/repo/v1/entity/syn22891469/wiki/605717). **Unavailable for this project**, with no validation/request/data. [Registry decision](../../configs/datasets/evidation-ili-2019-2020.toml). Homekit/ILI overlap is plausible, unproven; seek an owner statement, never reidentification.
- **CovIdentify:** 2,887 linked watches within 7,348 consents; 132 positive / 1,157 negative test reporters are not a verified wearable-paired intersection. Recovery completeness remains unverified. Access requires CITI approval, individual credentialing, then project DUA; **never shared `asus`**. [Official release](https://physionet.org/content/covidentify/1.0.0/). **Unavailable for this project**: manual credential review cannot finish in time; no data obtained. [Registry decision](../../configs/datasets/covidentify.toml). **CMU:** PR70 records all three analysis forms submitted and labels built, but no wearables; no CMU participant data was analyzed here.
- **New public malaria lead:** [Figshare 31444399](https://api.figshare.com/v2/articles/31444399) offers 300 people’s HR/RHR under CC BY 4.0. The [paper](https://www.nature.com/articles/s41746-026-02518-4) reports 161 malaria positives and ~50% coverage, but public metadata does **not establish released paired test/onset/recovery labels**. HR is not PPG. Its COVID component reuses Stanford phase 2; no independent COVID evidence follows. No download/admission occurred. A 4,795-person [prospective recovery study](https://pmc.ncbi.nlm.nih.gov/articles/PMC12992200/) instead releases aggregates, not accessible individual training pairs.

This bounded review found no newly held qualifying source; it does not prove none exists. For future work, prioritize Homekit onset/Evidation recovery through the human/registry route and a private paired-label audit. They cannot unblock this delivery. EHR events, untested days and missing surveys cannot become observed symptom-free negatives.

## Verified local labels preserve a narrow evidence boundary

CoralFrog independently verified existing local Stanford metadata at commit `f08fd01df9369101b7b0b31329a66e1d106f133c`, Python 3.12.13, isolated `.venv`/cache: source archive SHA256 `52ca976e6c08daa0cf34b6b82f4fc69b8894c1eef66e598efa40197df4e380f4`; phase 1 snapshot SHA256 `168d54133c8bc1c566f0b1a023d4f7ca04f54cecbadd3257fa4840e0031e8a33`; full verification **10 files, 0 problems**. No clinical scoring or outer-test evaluation occurred. Reproduce snapshot/fold checks locally with the private path supplied through `PRIVATE_CLINICAL_SNAPSHOT`:

```sh
.venv/bin/python -I - <<'PY'
import os
from pathlib import Path
from hachi.data.clinical import verify
from hachi.evaluation.clinical_protocol import ClinicalProtocol, clinical_fold_plan
from hachi.evaluation.serialization import document_sha256
snapshot = Path(os.environ['PRIVATE_CLINICAL_SNAPSHOT'])
result = verify(snapshot, full=True)
assert result['ok'], 'private snapshot verification failed'
protocol = ClinicalProtocol.model_validate_json(
    Path('configs/evaluation/stanford-phase1-clinical.json').read_text())
plan = clinical_fold_plan(snapshot, protocol)
print({'verified_files': result['checked']['files'],
       'fold_plan_sha256': document_sha256(plan)})
PY
```
